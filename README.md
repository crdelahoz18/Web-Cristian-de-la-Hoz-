# Web de Cristian de la Hoz

Home de la web de marca personal de Cristian de la Hoz, Project Manager de marketing digital para infoproductores, agencias y emprendedores.

Es una página estática: HTML y CSS en `index.html` e imágenes en `img/`. Para verla, abre `index.html` en el navegador o publícala con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
