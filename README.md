# Web de Cristian de la Hoz

Home de la web de marca personal de Cristian de la Hoz, Project Manager de marketing digital para infoproductores, agencias y emprendedores.

Es un sitio estático: la home en `index.html`, la página del ebook en `ebook.html`, las páginas legales (`aviso-legal.html`, `politica-privacidad.html`, `politica-cookies.html`), los estilos compartidos en `css/styles.css` e imágenes en `img/`. Para verla, abre `index.html` en el navegador o publícala con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
